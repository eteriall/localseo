## 0.1.0

First public release.

- Check Next.js, React and static websites on a local server.
- Follow links and check HTTP responses, robots rules, sitemaps and page tags.
- Read pages in Chromium and compare them with the HTML from the server.
- Check JSON-LD, Microdata and RDFa with a local copy of Schema.org data.
- Run extra checks for mobile pages, bot responses, images, video and build routes.
- Show an SEO Score with a coloured gauge. Mark the score when checks are incomplete.
- Save HTML, JSON, CSV and Markdown reports, and compare results with an older run.
- Set which problems should cause a failed run in CI.
- Run optional speed checks with Lighthouse.

See the [rule guide](docs/rules.md) for the full list and limits. The tool cannot confirm a page's position in Google or whether Google will index it.
