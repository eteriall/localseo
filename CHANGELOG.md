# Changelog

## 0.1.0

Initial public release.

- Local-first technical SEO auditing for Next.js, React and static websites.
- HTTP crawling, Chromium rendering, robots/sitemaps, metadata, canonicals, hreflang, links and images.
- JSON-LD, Microdata and RDFa validation with bundled Schema.org vocabulary and selected Google feature profiles.
- Bounded mobile, bot-response, lazy-content, resource MIME, image decoding, pagination and route-manifest checks.
- Technical SEO Score with a colored gauge and explicit provisional coverage.
- Standalone HTML reports, JSON/CSV/Markdown exports, baselines and configurable CI exit codes.
- Optional Lighthouse performance audits.

This is not a ranking prediction, production indexing check, or complete replacement for Google's Rich Results Test. See README and the rule guide for coverage boundaries.
